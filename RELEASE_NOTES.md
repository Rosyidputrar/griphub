## Bahasa Indonesia

- Keamanan: agent tidak lagi bisa menulis di luar folder proyek tanpa persetujuan lewat cara yang sebelumnya lolos: awalan `@` pada path, alamat `file://`, atau tautan (symlink) di dalam proyek yang menunjuk ke luar. Menulis ke dalam folder `.git` juga kini meminta persetujuan.
- Keamanan: git yang dijalankan aplikasi pada folder proyek (panel Git, daftar proyek, commit, menghapus proyek) tidak lagi menjalankan program yang disebut di pengaturan git proyek itu (misalnya `core.fsmonitor`, hook, `core.sshCommand`, driver filter atau diff). Bila pengaturan proyek menyebut program yang tak bisa dimatikan, git tidak dijalankan di sana dan alasannya ditampilkan: buka berkas `.git/config` dan hapus entrinya. Token juga tidak ikut ke proses git.
- Mode server: perintah di dalam box tidak lagi bisa menimpa berkas server (misalnya `authorized_keys` atau kunci penyimpanan) lewat tautan yang ditanam di folder home box. Pengaturan git dan ssh kini dikirim lewat `podman exec`, bukan disalin dari server, dan hanya dikirim ulang bila berubah atau setelah 30 detik.
- Pemasangan server: bila server sudah punya Node.js yang cukup baru di tempat lain (misalnya `/usr/bin/node` dari apt atau NodeSource), skrip kini membuat tautan `/usr/local/bin/node` yang dicari layanan. Sebelumnya layanan gagal start (status 203) di server seperti itu. Tautan yang sudah ada tidak pernah diganti: bila bukan Node yang cukup baru, skrip berhenti dan menyebut alasannya.
- Git: proyek yang memakai Git LFS kini ikut mengunggah file besarnya saat push. Aplikasi menjalankan git tanpa hook, sehingga hook `pre-push` milik LFS tidak jalan dan remote sebelumnya hanya menerima penunjuk tanpa filenya. Pengaturan LFS yang menjalankan program (ekstensi, agen transfer kustom) ditolak seperti pengaturan git lain yang berbahaya, sedangkan pengaturan yang ditulis `git lfs install` (termasuk `--skip-smudge`) tetap diterima.
- Agent tidak lagi macet selama berpuluh detik saat membaca pesan yang sangat besar (misalnya beberapa foto sekaligus): pemisah baris kini linear.
- Halaman web yang dibuat khusus untuk membekukan pembaca (ratusan KB tanda `<`) tidak lagi membuat agent berhenti menjawab saat mengubahnya menjadi teks; waktunya turun dari menit menjadi milidetik, hasil teksnya sama. Angka rujukan HTML yang bukan karakter (misalnya `&#99999999;`) tidak lagi membuat pembaca error.
- Mode server: agent yang terjebak satu perulangan dan tidak menjawab lagi kini dimatikan otomatis setelah dua menit (`GRIPHUB_WATCHDOG_MS`), lalu layanan memulainya ulang; sebelumnya ia menggantung sampai ada yang masuk lewat SSH.
- Data akun dan pengaturan lebih aman: file penyimpanan (login GitHub/Vercel/Cloudflare, host SSH, pengaturan, server MCP, jadwal, sinkron) ditulis utuh atau tidak sama sekali, dengan salinan terakhir yang baik di samping `.bak`. File yang tidak terbaca (terpotong, atau disimpan dengan kunci lain) tidak lagi dianggap kosong lalu ditimpa: file itu dipindah ke `.corrupt-<waktu>`, salinan terakhir dipakai bila ada, dan chat menampilkan pemberitahuan. Cadangan otomatis melewati penyimpanan yang tidak terbaca (dulu tersimpan sebagai `null` yang lalu menimpa data asli saat dipulihkan).
- Berpindah chat atau membangun ulang sesi kini membangun sesi baru dulu; bila gagal, chat yang sedang terbuka tetap berfungsi, tidak lagi menjadi sesi mati. Dua perpindahan sekaligus dijalankan bergantian.
- Persetujuan yang dijawab saat koneksi ke server putus tidak lagi hilang: kartunya kembali ke antrean dan muncul pesan alasannya. Selama koneksi putus, tombol Tolak/Selalu/Izinkan mati dan kartu menjelaskan bahwa agent masih menunggu jawabanmu.
- Tombol Stop, mode Rencana, dan tingkat berpikir kini memberi tahu bila gagal. Stop saat koneksi ke server putus menjelaskan bahwa ia tidak bisa menjangkau server, dan Stop yang berhasil menampilkan "Menghentikan…".
- Key GripHub yang salah ketik kini dibaca sebagai key yang salah ("Key ditolak. Pastikan tersalin utuh, tanpa spasi.") dan bukan balasan HTTP mentah berbahasa Inggris. Router yang tidak menjawab dan galat lain juga dijelaskan.
- Bypass semua izin: dialognya kini menyebut bahwa pengaturan ini berlaku untuk semua chat sampai dimatikan di Pengaturan > Persetujuan, tombolnya berwarna bahaya, dan selama aktif chat menampilkan bilah "Izin dilewati" dengan tombol Matikan. Pengaturan Persetujuan juga menyatakan bahwa ia hanya pertanyaan untuk tindakan berisiko yang umum, bukan batas keamanan.
- Layar Tugas kini menjelaskan apa yang boleh dilakukan tugas latar tanpa bertanya: di HP ia berjalan tanpa persetujuan apa pun pengaturannya, di server tindakan berisiko ditolak.
- Review & commit: tiap file punya kotak centang, dan commit hanya memuat file yang dicentang (dulu `git add -A` memasukkan semuanya, termasuk `.env` yang belum pernah dilihat). File yang tampak berisi rahasia (`.env`, kunci privat, kredensial) tidak tercentang dan diberi tanda. Tombol push menyebut tujuannya: "Commit & push ke origin/<cabang>".
- Batas anggaran harian dan batas panggilan tool kini tampil sebagai kesalahan berbahasa Indonesia dengan angka berformat Indonesia, dengan tombol "Naikkan batas" yang membuka Pemakaian. Merencanakan lalu menjalankan, memulai subagent, dan membuat gambar kini juga menghormati anggaran harian (dulu hanya pesan dan coba lagi yang memeriksa).
- Keamanan: web_fetch tidak lagi menjangkau mesin ini, jaringan pribadi, atau layanan metadata server cloud, termasuk lewat pengalihan (redirect). Membaca file yang menyimpan rahasia (kunci penyimpanan, token, kunci ssh, `/proc/<pid>/environ`) kini ditanyakan dulu, dan ditolak pada tugas tanpa pengawas. Ini daftar, bukan tembok: perintah shell yang cerdik masih bisa lolos.
- Kartu saran di chat kosong tidak lagi terpotong di HP 360 dp atau dengan teks besar.
- Menu bawah (menu chat dan proyek, menu file, Bagikan chat, lampiran) kini bisa digulir sampai baris terakhir, juga saat HP dimiringkan; dulu "Hapus" terpotong dan tidak terjangkau.
- Layar pengenalan dan layar API key tidak lagi meluap di HP kecil, HP miring, atau teks besar. Tombol Lewati lebih mudah disentuh, dan titik halaman menyebut halaman ke berapa untuk pembaca layar.
- Teks yang masih berbahasa Inggris di mode Indonesia (pesan layar File, "Committed", daftar chat kosong, jumlah server, "preparing…", jumlah langkah CI dan baris database) kini diterjemahkan.
- Saat server sudah diatur, judul chat tidak lagi terjepit di HP sempit atau teks besar: Terminal, Deploy, dan Alat proyek pindah ke menu Lainnya, dan lencana koneksi menjadi ikon saja bila sangat sempit.
- Pilihan warna aksen bisa dipakai dengan pembaca layar (menyebut nama warna dan mana yang terpilih) dan punya area sentuh 48 dp; judulnya tidak lagi patah per suku kata.
- Tombol salin di bawah jawaban kini punya label, tooltip, area sentuh 48 dp, dan mengumumkan "Disalin".
- Tombol berbahaya (hapus, hentikan) terbaca di mode gelap, dan warna aksen hijau, oranye, merah muda, dan toska kini terbaca sebagai teks di mode terang.
- Daftar chat yang gagal dimuat kini menampilkan pesan dan tombol Coba lagi, tidak lagi kosong atau berputar selamanya.
- Jawaban panjang yang sedang mengalir tidak lagi makin berat seiring panjangnya: bagian yang sudah selesai tidak diurai ulang setiap frame, dan tampilan diperbarui sekitar 30 kali per detik.
- Diff yang sangat panjang (ribuan baris) kini langsung terbuka: hanya baris yang tampil di layar yang dibangun.
- Ikon status bar kini mengikuti tema di setiap layar, termasuk Beranda dan layar pengenalan.
- Kontrol kecil (chip kategori Beranda, tombol pencarian, tab baru Terminal, lencana koneksi, bilah pilihan Chats) kini punya area sentuh 48 dp.
- Animasi di seluruh aplikasi kini mengikuti pengaturan sistem "hapus animasi".
- Tab Chats tetap ringan dengan ratusan chat: hanya baris yang tampil yang dibangun, dan baris tidak dibangun ulang setiap kali agent memberi kabar.
- Pembaca layar kini membacakan apa yang sedang dikerjakan agent, hasil tool (selesai, gagal, berjalan), apakah panel terbuka, nama lampiran dan foto, dan judul baris bersakelar cukup sekali.
- Di tablet, perangkat lipat, dan HP miring, isi aplikasi tetap selebar yang nyaman dibaca, gelembung pesan tidak melebar penuh, dan kartu proyek menambah kolom.
- Tombol Kembali di tab Chats, Skill, atau Proyek kini kembali ke Beranda, tidak langsung menutup aplikasi.
- Teks pill, ikon di kotak berwarna, komentar kode, kartu Hubungkan di mode gelap, dan spinner CI kini cukup kontras.

## English

- Security: the agent can no longer write outside the project folder without approval in ways that used to slip through: a leading `@` on a path, a `file://` address, or a link (symlink) inside the project that leads out. Writing into a `.git` folder now asks too.
- Security: the git the app runs on project folders (the Git panel, the project list, commits, deleting a project) no longer runs programs named in that project's git settings (for example `core.fsmonitor`, hooks, `core.sshCommand`, filter or diff drivers). When a project's settings name a program that cannot be turned off, git is not run there and the reason is shown: open the `.git/config` file and remove the entry. Tokens no longer go along to git processes either.
- Server mode: a command in the box can no longer overwrite the server's files (such as `authorized_keys` or the store key) through links planted in the box's home folder. The git and ssh settings are now sent through `podman exec` instead of being copied from the server, and sent again only when they change or after 30 seconds.
- Server setup: when the server already has a new enough Node.js somewhere else (for example `/usr/bin/node` from apt or NodeSource), the script now makes the `/usr/local/bin/node` link the service looks for. The service used to fail to start (status 203) on such servers. A link that is already there is never replaced: if it is not a new enough Node, the script stops and says why.
- Git: projects that use Git LFS now upload their large files on push too. The app runs git with hooks off, so LFS's `pre-push` hook never ran and the remote only got pointers with no files behind them. LFS settings that run programs (extensions, a custom transfer agent) are refused like other git settings that would, while what `git lfs install` writes (`--skip-smudge` included) is accepted.
- The agent no longer freezes for tens of seconds reading a very large message (for example several photos at once): the line splitter is now linear.
- A web page built to freeze its reader (hundreds of KB of `<`) no longer makes the agent stop answering while it is turned into text; the time drops from minutes to milliseconds, with the same text out. An HTML character reference that is no character (such as `&#99999999;`) no longer makes the reader fail.
- Server mode: an agent stuck in one loop and no longer answering is now killed after two minutes (`GRIPHUB_WATCHDOG_MS`) and the service restarts it; before, it hung until someone logged in over SSH.
- Sign-ins and settings are safer: the storage files (GitHub/Vercel/Cloudflare sign-ins, SSH hosts, settings, MCP servers, schedules, sync) are written whole or not at all, with the last good copy kept beside them as `.bak`. A file that cannot be read (cut short, or saved with another key) is no longer taken for an empty one and written over: it is moved to `.corrupt-<time>`, the last copy is used when there is one, and the chat shows a notice. Automatic backups leave out a store that cannot be read (it used to be saved as `null`, which then overwrote the real data when restored).
- Switching chats or rebuilding the session now builds the new session first; if that fails, the open chat keeps working instead of becoming a dead session. Two switches at once run one after the other.
- An approval answered while the link to the server is down is no longer lost: the card goes back into the queue and says why. While the link is down the Deny/Always/Allow buttons are off and the card says the agent is still waiting for your answer.
- Stop, Plan mode and the thinking level now tell you when they fail. Stop with the server link down explains that it cannot reach the server, and a Stop that went through says "Stopping…".
- A mistyped GripHub key now reads like a wrong key ("The key was not accepted. Check that you copied all of it, with no spaces.") instead of the router's raw HTTP reply in English. A router that does not answer, and other failures, are explained too.
- Bypass all permissions: the dialog now says the setting applies to all chats until you turn it off in Settings > Approvals, its button is danger-coloured, and while it is on the chat shows a "Permissions bypassed" bar with a Turn off button. The Approvals setting also says it is prompts for common risky actions, not a security boundary.
- The Tasks screen now says what a background run may do without asking: on the phone it runs with no approval whatever the setting is, on a server risky actions are refused.
- Review & commit: every file has a checkbox, and the commit contains only the ticked files (it used to run `git add -A` and take everything, including a `.env` never looked at). A file that looks like a secret (`.env`, private keys, credentials) starts unticked and is flagged. The push button names its target: "Commit and push to origin/<branch>".
- The daily budget and tool-call limits now show as errors in your language with your number format, with a "Raise limit" button that opens Usage. Carrying out a plan, starting a subagent and generating a picture now respect the daily budget too (before, only sending a message and retrying checked it).
- Security: web_fetch no longer reaches this machine, private networks or a cloud server's metadata service, including through redirects. Reading files that hold secrets (the store key, tokens, ssh keys, `/proc/<pid>/environ`) is now asked about first, and refused in an unattended run. These are lists, not a wall: a clever shell command can still get past them.
- The suggestion cards on an empty chat are no longer cut off on a 360 dp phone or with large text.
- Bottom menus (the chat and project menus, file menus, Share chat, attachments) now scroll to their last row, also with the phone on its side; "Delete" used to be cut off and out of reach.
- The welcome screens and the API key screen no longer overflow on a small phone, a phone on its side or with large text. Skip is easier to hit, and the page dots tell a screen reader which page this is.
- Text that was still English in the Indonesian UI (Files messages, "Committed", the empty chat list, server counts, "preparing…", CI step and database row counts) is now translated.
- With a server set up, the chat's title is no longer squeezed on a narrow phone or with large text: Terminal, Deploy and Project tools move into a More menu, and the connection badge becomes an icon when space is very tight.
- The accent colour choices work with a screen reader (each says its colour and which is chosen) and have 48 dp touch targets; their title no longer breaks into syllables.
- The copy button under a reply now has a label, a tooltip, a 48 dp touch target, and announces "Copied".
- Danger buttons (delete, stop) read in the dark theme, and the green, orange, pink and teal accents now read as text in the light theme.
- A chat list that fails to load now shows the error with Try again, instead of staying blank or spinning forever.
- A long streaming reply no longer gets heavier as it grows: finished parts are not re-parsed every frame, and it updates about 30 times a second.
- Very long diffs (thousands of lines) open at once: only the rows on screen are built.
- The status bar icons follow the theme on every screen, Home and the welcome screens included.
- Small controls (Home's category chips, the search toggles, the terminal's new tab, the connection badge, the Chats selection bar) have 48 dp touch targets.
- Animations across the app follow the system's remove-animations setting.
- The Chats tab stays light with hundreds of chats: only the rows on screen are built, and they are not rebuilt every time the agent reports.
- Screen readers now hear what the agent is doing, how a tool went (done, failed, running), whether a panel is open, the names of attachments and photos, and a switch row's title only once.
- On tablets, foldables and phones on their side the content keeps a readable width, message bubbles stop widening, and project tiles add columns.
- Back on the Chats, Skills or Projects tab now goes to Home instead of closing the app.
- Pill text, icons on coloured tiles, code comments, the Connect card in the dark theme and the CI spinner now have enough contrast.
- Text size is held to 2.2x (the app's setting times the system's used to reach 2.5x).
- Illustrations always show once loaded, instead of sometimes missing.
- A subagent's details now read like the chat: its thinking, the text it wrote between steps, each tool, and the messages you sent it, in order. Bash commands show whole with syntax highlighting and Copy, written files show their content, edits show their changes, and tool output (up to 16k characters) can be copied. Pictures from tools show too.
- While a subagent writes a file, its content shows live line by line, as do its thinking and text.
- Queued messages already sent to a subagent now stay visible among its steps instead of disappearing.
- A subagent's details follow the newest step once you scroll to the bottom, and stop following when you scroll up to read. A Scroll to bottom button takes you back.
- A subagent can be shared as Markdown (its task, steps and report): as text, as a file, copied, or saved to Downloads.
- Screen readers now say each subagent tool's status (done, failed, running) and whether its card is open.
- The server's automatic backups no longer balloon: dot folders in the workspace (for example `.toolchains`, holding a JDK and the Android SDK) and build output folders (`build`, `target`, `dist`) are left out, while `.git`, `.env` and project files stay in. Leftovers of a backup that was cut short are also cleaned away instead of piling up in the backups folder.
